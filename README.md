# VehicleCare — Цифровий Гараж з AI-Механіком

**VehicleCare** — це веб-додаток для автоматизації технічного обслуговування автомобіля. Проєкт реалізований як дипломна робота, що демонструє інтеграцію сучасних ШІ-технологій у прикладне ПЗ.

## 🚀 Основні можливості
* **AI-Механік:** Інтелектуальний чат-бот на базі Cohere Command R+, який автоматично діагностує симптоми та створює записи в журналі ремонтів.
* **Гараж:** Керування даними авто, відстеження пробігу та планування ТО.
* **Аналітика:** Графіки витрат та статистика поломок по вузлах автомобіля.
* **Генерація звітів:** Експорт актуальних проблем у PDF-файл для СТО.

## 🛠 Технологічний стек
* **Backend:** FastAPI (Python), SQLAlchemy.
* **Frontend:** HTML5, CSS3 (з підтримкою темної теми), JavaScript (Vanilla).
* **Database:** SQLite.
* **AI Core:** Cohere API (Pattern: Function Calling / AI Agents).

📝 Технічний опис етапів:
Клієнтський рівень (Frontend): Користувач взаємодіє з інтерфейсом чату, надсилаючи неструктурований текст.

Проміжний рівень (API Gateway): FastAPI виступає посередником. Він не просто пересилає текст, а додає до нього динамічний контекст із бази даних: марку авто, модель та актуальний пробіг.

Інтелектуальне ядро (Cohere Command R+): Нейромережа аналізує наміри користувача. Якщо вона ідентифікує поломку, вона ініціює паттерн Function Calling.

Рівень даних (Database): Backend виконує інструкції ШІ та створює структурований запис у таблиці issues бази даних SQLite.

Зворотний зв'язок: Система повертає користувачу підтвердження у форматі природної мови, закриваючи цикл взаємодії

```mermaid
graph TD
    A[Користувач / Frontend] --> B(FastAPI Backend)
    B --> C{Cohere AI Core}
    C --> D[(SQLite Database)]
    D --> B
    B --> A
\``` (тут три зворотні лапки)

## 📦 Інструкція із запуску
1. Встановіть залежності: `pip install -r backend/requirements.txt`
2. Створіть файл `backend/.env` та додайте ваш ключ: `COHERE_API_KEY=ваш_ключ`
3. Запустіть сервер: `python -m uvicorn main:app --reload` всередині папки `backend`.
4. Відкрийте `frontend/index.html` у браузері.
