# VehicleCare — Цифровий Гараж з AI-Механіком

**VehicleCare** — це веб-додаток для автоматизації технічного обслуговування автомобіля. Проєкт реалізований як дипломна робота, що демонструє інтеграцію сучасних ШІ-технологій у прикладне ПЗ.

## 🚀 Основні можливості
* **AI-Механік:** Інтелектуальний чат-бот на базі Cohere Command R+, який автоматично діагностує симптоми та створює записи в журналі ремонтів.
* **Гараж:** Керування даними авто, відстеження пробігу та планування ТО.
* **Аналітика:** Графіки витрат та статистика поломок по вузлах автомобіля.
* **Генерація звітів:** Експорт актуальних проблем у PDF-файл для СТО.

## 🛠 Технологічний стек
* **Backend:** FastAPI (Python), SQLAlchemy.
* **Frontend:** HTML5, CSS3 (з підтримкою темної теми), JavaScript (Vanilla).
* **Database:** SQLite.
* **AI Core:** Cohere API (Pattern: Function Calling / AI Agents).

📝 Технічний опис етапів:
Клієнтський рівень (Frontend): Взаємодія через чат-інтерфейс.

Проміжний рівень (API Gateway): FastAPI збагачує запит контекстом автомобіля з БД.

Інтелектуальне ядро (Cohere Command R+): Аналіз намірів та використання Function Calling.

Рівень даних (Database): Автоматичне логування задач у SQLite.

📦 Інструкція із запуску
Встановіть залежності: py -m pip install -r requirements.txt

Створіть файл backend/.env та додайте ваш ключ: COHERE_API_KEY=ваш_ключ

Запустіть сервер: py -m uvicorn main:app --reload

Відкрийте index.html у браузері.
